# 증강 피구 청백전 · 수정본

## 적용

기존 `src`를 백업한 뒤, ZIP 안의 `src` 폴더로 교체하세요. 프로젝트 루트의 package.json, Vite·TypeScript 설정은 그대로 사용합니다. React + TypeScript + Vite 프로젝트이며, 추가 npm 패키지는 필요하지 않습니다.

```bash
yarn dev
```

실행 파일은 App.tsx, App.css, game.ts, useGame.ts, shortcuts.ts, VictoryEffects.tsx, index.css, main.tsx입니다. 아이콘은 소스 안의 SVG이고, 알림음은 Web Audio로 생성하므로 별도 이미지·음원 파일이 필요하지 않습니다. index.html에는 Vite 기본값인 `<div id="root"></div>`가 있어야 합니다.

## 운영 순서

1. 행사명, 주장, 라운드별 인원, 시간을 설정합니다. 첫 화면에는 선공 선택이나 규칙 확인 체크가 없습니다.
2. **게임 시작**을 누른 후 1라운드 선공을 고릅니다. 2라운드 선공은 자동으로 반대팀이 됩니다. 공을 나중에 던지는 팀이 정규 증강을 먼저 선택합니다.
3. 선공 설정 후 진행 방식·안전 규칙·9개 증강·조기선택을 설명하는 17장 슬라이드가 열립니다. 이전·다음 버튼은 빔 화면에도 함께 반영됩니다.
4. 설명과 준비가 끝나면 **1라운드 시작**을 누릅니다. 준비 시간이 0이 되어도 경기가 임의로 시작되지 않습니다.
5. 판정에 맞춰 아웃·부활·인원 수정·직전 판정 취소를 클릭합니다. 조기선택도 같은 버튼으로 조작합니다.
6. 1라운드 종료 시 즉시 **다음 라운드 준비해주세요** 화면이 나옵니다. 선수 교체 후 진행자가 **2라운드 시작**을 누릅니다.
7. 두 라운드가 끝나면 결과를 확인하고 **행사 종료**를 누릅니다.

## 이번 수정

- 9개 증강 설명을 요청한 문구로 변경하고 개발용 caution 문구를 제거했습니다. 첫 피격 보호는 첫 번째 유효 피격 기준입니다.
- 1·2·3단계 증강 소개 직전에 중앙에 단계 이름을 크게 표시하는 표지를 각각 추가했습니다.
- 안전 안내 제목은 **안전 유의사항!**입니다. 짐볼 어깨 높이 제한 문구를 제거하고, 신체 접촉·진로 방해는 지양으로 변경했습니다.
- **호루라기를 불 경우에만 아웃이며, 아웃이 아니라면 불지 않는다**는 별도 슬라이드를 추가했습니다.
- 1라운드 선공을 변경하면 아직 시작하지 않은 2라운드 선공도 반대로 변경됩니다.
- 이전 버전 기본 증강 설명은 저장 기록을 읽을 때 새 설명으로 갱신합니다. 직접 편집한 설명은 보존하므로 필요하면 카드 상세 문구 편집에서 수정하세요.

## 시간 조절

- 준비, 1라운드, 교체, 2라운드, 마무리를 각각 0.5~120분으로 설정할 수 있습니다. 기본값은 5분 / 15분 / 2분 / 15분 / 3분입니다.
- 각 라운드 시계는 진행자가 실제로 시작한 시각부터 계산합니다.
- 현재 구간에 **추가 +1분**, **추가 +3분**, **추가 시간 직접 입력**으로 시간을 더합니다. 준비가 이미 0초여도 요청한 추가 시간이 전부 부여됩니다.
- **현재 라운드 조기 종료**는 확인 후 즉시 현재 생존 인원으로 결과를 기록하고 다음 준비 화면으로 전환합니다. 2라운드에서는 결과·마무리 화면으로 전환합니다.
- 라운드의 설정 시간이 끝나거나 한 팀이 전멸하면 해당 라운드는 종료됩니다. 다음 라운드와 행사 전체의 종료는 진행자가 결정합니다. 행사 전체의 고정 자동 종료 시각은 없습니다.
- 증강 정규 선택 시점은 라운드 시작 / 경과 6분 / 경과 12분입니다. 추가 시간은 이 시점을 옮기지 않습니다. 라운드를 짧게 설정·종료하면 도달하지 않은 단계는 열리지 않습니다.

## 팀별 증강 선택과 지정 선수

- 증강 선택 시간은 **각 팀 40초씩**입니다. 첫 팀이 끝나면 두 번째 팀에 새 40초가 주어집니다. 단독 조기선택도 40초입니다.
- 경기 시계는 선택 중에도 흐릅니다. 라운드 종료 시각이 더 먼저 오면 남은 선택 시간도 종료됩니다. 필요하면 선택 화면에서 경기 시간 +1분을 누르세요.
- 시간 초과 시 해당 팀의 왼쪽 카드가 자동 확정됩니다. 다음 팀의 시간이 남아 있으면 다음 팀 선택이 이어집니다.
- 자폭병·첫 피격 보호: 우리 선수 1명. 커플 저주: 상대 선수 2명. 외야 봉인: 선택 당시 영향을 받는 상대 외야수 수만큼 입력합니다.
- 이름 또는 구별 가능한 등번호를 입력합니다. 같은 지정 안에서 중복·빈 이름은 허용하지 않습니다. 수동 확정은 필요한 이름을 모두 입력해야 가능합니다.
- 시간 초과로 자동 확정된 지정형 카드에 이름이 없으면 **지정 선수** 창에서 보완합니다. 기존 이름도 이 창에서 수정할 수 있습니다. 외야 봉인의 인원 수는 선택 당시 기준으로 고정됩니다.
- 첫 조기선택은 현재 인원의 절반 이상 아웃일 때 활성화됩니다. 이미 첫 기회를 사용했어도 생존자 1명일 때 같은 버튼이 다시 활성화됩니다. 미선택 다음 단계가 있어야 하며, 팀당 조기선택 최대 2회·증강 총 3개입니다.

## 빔 화면과 소리

**빔 화면 열기**로 같은 브라우저의 새 창을 열고 빔 디스플레이로 옮긴 뒤 전체화면을 누르세요. 운영자 창과 빔 창은 같은 컴퓨터·브라우저·주소에서 자동 동기화됩니다. 다른 기기 간 인터넷 동기화 기능은 없습니다.

선택 화면은 청팀이면 진한 파랑, 백팀이면 밝은 배경으로 바뀌며 **지금은 청팀/백팀 차례**를 크게 표시합니다. 보유 증강은 큰 SVG 그림, 카드 이름과 요약으로 표시합니다. 빔 화면에는 보유 증강의 대상, 상대 효과의 지정 선수, 선택 중 입력하는 이름을 표시하지 않습니다. 대상 정보는 운영자 화면에만 표시합니다.

운영자 창의 **삐용 소리 테스트**로 출력 장치를 확인하세요. 증강 선택·팀 전환 시 주파수가 오르내리는 알림음이 납니다. 음량 슬라이더와 음소거 버튼을 제공합니다. 실제 음량은 시스템·스피커 설정에도 영향을 받습니다.

## 단축키와 최종 승리 연출

클릭 조작과 다음 단축키를 함께 사용할 수 있습니다.

| 키 | 동작 |
| --- | --- |
| A | 청팀 1명 아웃 |
| S | 청팀 1명 부활 |
| K | 백팀 1명 아웃 |
| L | 백팀 1명 부활 |
| Ctrl+Z / Cmd+Z | 직전 판정 취소 |

이름 입력·설정 창·규칙 설명·증강 선택 중, 빔/읽기 전용 창에서는 단축키가 판정에 적용되지 않습니다. 키를 길게 눌러도 반복 판정하지 않습니다. 한글 조합 입력 중에도 무시합니다.

최종 승리팀이 결정되면 우승팀 색상의 무대, 큰 우승 문구, 금빛 트로피와 함께 폭죽·꽃가루가 계속 재생됩니다. 승리 화면을 벗어나면 효과를 정리하고, 창이 숨겨지면 애니메이션을 일시 중단합니다. OS의 동작 줄이기 설정을 켠 경우에는 정적인 우승 화면을 표시합니다. 라운드 결과나 최종 동률 미확정 상태에서는 우승 효과를 재생하지 않습니다.

## 저장·복구

- 실전과 연습은 별도로 자동 저장됩니다. 새로고침 시 선택 후보·선수 이름·팀별 제한 시각·조정된 마감 시각을 유지합니다.
- JSON 내보내기·가져오기로 기록을 백업할 수 있습니다. 구버전 1·2 저장 구조를 이전하는 코드가 포함되어 있습니다. 구버전의 고정 행사 종료 시각은 새 방식에서 사용하지 않습니다.
- 실행 중인 운영자 창 하나만 기록을 수정합니다. 빔 창과 다른 운영자 창은 읽기 전용입니다.
- 새로고침·탭 비활성 중에도 실제 시간은 흐릅니다. 연습 모드에서만 일시정지·시간 이동을 제공합니다.
- 직전 판정 취소는 판정 전 인원을 복원하며 시계·선택 카드를 되돌리지 않습니다. 전멸 직후에는 원래 경기 시간이 남아 있고 다음 라운드가 시작되지 않은 경우 복구할 수 있습니다. 시간 만료·수동 종료는 취소로 재개하지 않습니다.

## 검증

규칙·상태 전환 테스트 60개를 통과했습니다. 선공 자동 배정·17장 이동·저장 복구·새 문구 관련 테스트 7개와 슬라이드 구성 검사도 통과했습니다. 여기에 무작위 조작 1,500회 상태 검증이 포함됩니다. 단축키 테스트 11개와 화면 구성 요소의 대상 정보 비노출·우승 연출 조건 검사 8개도 통과했습니다. TypeScript/JSX 6개 파일의 구문 변환을 확인했습니다. 화면 구성 요소 검사는 모의 JSX 환경 검사이며 실제 브라우저 렌더링 검사가 아닙니다.

Node.js 24에서 프로젝트 루트 기준 다음 명령으로 규칙 테스트를 재실행할 수 있습니다.

```bash
node src/__tests__/scenarios.mjs
node src/__tests__/shortcuts.mjs
node src/__tests__/intro.mjs
```

이 제작 환경에서는 React/Vite 설치와 실제 브라우저 실행이 불가능하여, `yarn build` 타입 검사·브라우저 화면·팝업 동기화·실제 스피커 음량은 검증하지 못했습니다. 현장 사용 전 로컬에서 빌드와 연습 모드 진행을 확인하세요. 테스트 결과는 `__tests__/results.txt`에 있습니다.
